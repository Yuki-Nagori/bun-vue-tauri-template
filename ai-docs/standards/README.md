# 规范索引

这些规范用于 task 的实现与评审。来自官方文档的规则附依据，标为「项目约定」的条目以本仓库决定为准。

## 索引

| 主题               | 文档                         | 何时阅读                       |
| ------------------ | ---------------------------- | ------------------------------ |
| 提交一致性         | [提交规范](commits.md)       | 每次提交前                     |
| 前端约定           | [前端](frontend.md)          | 改动 `src-web/`                |
| Rust / Tauri 约定  | [Rust](rust.md)              | 改动 `src-tauri/`、`src-rust/` |
| 注释规范           | [注释](comments.md)          | 写 / 改自有代码的注释          |
| 测试、覆盖率与基准 | [测试规范](testing.md)       | 新增 / 移动测试，动门禁口径    |
| 文档与图表         | [文档规范](documentation.md) | 新建 / 修改文档                |

## 文档职责

| 内容                           | 维护位置                                         |
| ------------------------------ | ------------------------------------------------ |
| 目标架构、分层边界、版本口径   | [架构总览](../architecture/README.md) 及主题文档 |
| 长期编码规则                   | 对应规范篇                                       |
| 单次工作的范围、决策与验证证据 | 对应 task                                        |
| 任务依赖、状态摘要             | [任务索引](../task-index.md)                     |

task 里验证过的探索结论应沉淀回架构或规范篇；task 保留过程与证据，不成为长期规则的唯一存放处。官方资料与已锁定版本不一致时，以所用版本的实际行为为准，在 task 记录原因并同步规范。
